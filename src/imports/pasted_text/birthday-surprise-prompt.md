Create a fully interactive, responsive birthday surprise website for a person named **Gaurav**.

IMPORTANT: This must be a **multi-page / multi-screen interactive experience**, NOT a single long scrolling webpage.

Each stage should behave like a separate full-screen page. The user should click buttons to transition from one page to another. Do NOT stack all sections vertically on one page.

The experience should feel like opening a beautifully designed digital birthday gift — playful, romantic, warm, surprising, and personal, but still aesthetically sophisticated. Avoid anything childish, tacky, overly glittery, or cringe.

## OVERALL DESIGN DIRECTION

Create a premium interactive aesthetic inspired by:

* Soft lavender
* Deep purple
* Warm cream
* Dusty pink
* Subtle gold accents
* Small amounts of red/pink for hearts
* Elegant typography
* Soft shadows
* Rounded cards
* Paper / letter textures
* Subtle grain
* Gentle animations
* Floating particles and occasional confetti

Typography should combine:

* An elegant serif/display font for emotional headings
* A clean modern sans-serif for buttons and small text
* Occasional italic/script-like typography for romantic phrases

The design should feel like a combination of:
**digital scrapbook + romantic letter + birthday surprise box + modern interactive website.**

Keep everything centered and beautifully balanced.

The website must be fully responsive for desktop and mobile.

On mobile:

* Buttons must remain easy to tap
* Text must never overflow
* Cards must fit within the viewport
* Animations should remain smooth
* Do not require horizontal scrolling

## VERY IMPORTANT NAVIGATION RULE

This is a sequence of separate interactive screens.

Never turn this into one scrolling page.

Use buttons such as:

* Next →
* Continue →
* Keep going →
* Open
* Replay ↻
* ← Back

Buttons should transition to the appropriate screen with a smooth animation such as fade + slight slide/scale.

The browser should feel like the user is moving through a story.

# BACK BUTTON BEHAVIOR

Back buttons must NEVER randomly go to unrelated pages.

Use this exact intended navigation:

Gift 1 → Back → Gifts

Envelope → Back → Gifts

Memory Lane → Back → Gifts

If the user later adds more intermediate screens, the Back behavior should ideally return to the immediately previous screen in the journey.

Do not use a generic webpage scroll-back behavior.

# INTERACTION DETAILS

Add micro-interactions:

* Buttons slightly lift on hover
* Buttons compress slightly when clicked
* Gift boxes bounce gently
* Envelope seal reacts to hover
* PIN buttons have tactile feedback
* Photos have subtle hover movement
* Confetti should be subtle and not cover text
* Page transitions should never feel abrupt

Do not autoplay music.

Do not create a scrolling landing page.

Do not place all content on one canvas vertically.

Every stage must function as an independent full-screen screen/page connected through interactive buttons.
